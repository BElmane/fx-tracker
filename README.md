# FX Tracker

# Problem
Exchange rates change over time, which affects how much money a person receives when converting from one currency to another. It's difficult to track rates 
manually and know when a good time to convert or send money is.

# Users
Anyone who regularly converts or sends money between currencies, such as people sending or receiving international transfers or tracking exchange rates before 
making a currency exchange. This includes students like myself whose families send money internationally to help cover expenses.

# Solution
A Python application that lets users select supported currency pairs, view current exchange rates, track rate history over time, and set a target rate to 
be notified when it's met.

# Technology
Python, using the Frankfurter v2 API for exchange rate data and the requests library. GUI framework and storage method will be finalized during Sprint 1.

# Status
Currently in planning (Weeks 1–4). Prototype development will begin Week 5.
